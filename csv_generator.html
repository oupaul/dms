方法一：從 Excel 貼上
使用說明（階層欄位格式）：
  1. 第一欄 (A)：第一階資料夾（根目錄）
  2. 第二欄 (B)：第二階資料夾（第一欄的子資料夾）
  3. 第三欄 (C)：第三階資料夾（第二欄「同一行」的子資料夾）
  4. 選取資料後複製（Ctrl+C），在下方貼上（Ctrl+V）
  5. 系統會自動解析階層關係並轉換為 CSV 格式
範例 Excel 格式：
Share 董事長
總經理
管理部 財務
人事
結果：Share → 董事長、總經理、管理部 → (管理部下) 財務、人事

方法二：階層式輸入
使用說明：
  1. 使用縮排（空格或Tab）表示資料夾的層級關係
  2. 同層級的資料夾使用相同的縮排量
  3. 子資料夾比父資料夾多一層縮排（建議使用 2 或 4 個空格）
  4. 系統會自動偵測縮排單位並計算 parent_id
  5. 重要：父資料夾必須先於子資料夾輸入
範例：
公司 ← 第一層（根資料夾）
  管理部 ← 第二層（縮排2格）
    財務組 ← 第三層（縮排4格）
    人事組 ← 第三層（縮排4格）
  技術部 ← 第二層（縮排2格）
解析後的資料夾結構會顯示在這裡...
方法三：路徑格式（Windows / Linux NAS）
使用說明：

每行貼上一條路徑，系統自動辨識分隔符並建立階層。伺服器位址、磁碟代號、掛載點會自動略去。

🪟 Windows UNC / 磁碟路徑：
\\NAS01\Share\管理部\財務組
\\Server\Data\技術部
D:\Share\業務部\業務一組
🐧 Linux / Synology / QNAP：
/volume1/Share/管理部/財務組
/mnt/nas/Data/技術部
/shares/公司/業務部
💡 去重機制：相同路徑段只建立一個資料夾節點，貼上再多路徑也不會重複。貼上後自動解析。
解析後的資料夾結構會顯示在這裡...
