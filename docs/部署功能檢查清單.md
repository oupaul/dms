# 部署功能檢查清單

## ✅ 已實現的功能

### 1. 部署到 /opt 下，可自定義資料夾名稱
- **狀態**：✅ 已實現
- **位置**：`deploy.sh` 步驟 1
- **功能**：
  - 預設安裝到 `/opt/folder-permission-system`
  - 可自定義資料夾名稱（只允許英數字、底線、連字號）
  - 自動驗證資料夾名稱格式

### 2. 可自定義服務 Port
- **狀態**：✅ 已實現
- **位置**：`deploy.sh` 步驟 2
- **功能**：
  - 預設 Port：5000
  - 可自定義 Port（1024-65535）
  - 自動驗證 Port 範圍
  - 自動更新 `app.js` 中的 PORT 配置
- **注意**：佈署後請確認連線網址與 Nginx（若有）使用**同一 Port**，否則可能出現 502；可依 `app.js` 內 `const PORT = ?` 確認實際監聽 port。

### 3. 可自定義服務名稱（PM2 進程名稱）
- **狀態**：✅ 已實現
- **位置**：`deploy.sh` 步驟 3
- **功能**：
  - 預設使用資料夾名稱作為服務名稱
  - 可自定義服務名稱（獨立於資料夾名稱）
  - 自動更新 `ecosystem.config.js` 中的服務名稱
  - 所有 PM2 命令使用自定義服務名稱

### 4. 可自定義瀏覽器分頁顯示名稱
- **狀態**：✅ 已實現
- **位置**：`deploy.sh` 步驟 4
- **功能**：
  - 預設標題：「資料夾權限文管系統」
  - 可自定義標題
  - 自動更新 `index.html` 和 `login.html` 中的標題

### 5. 可自定義備份排程時間選單
- **狀態**：✅ 已實現
- **位置**：`deploy.sh` 備份配置部分
- **功能**：
  - 提供多個預設時間選項（凌晨 2:00、3:00、4:00、5:00、6:00）
  - 支援自定義時間（HH:MM 格式，24小時制）
  - 自動配置 cron job
  - 自動更新日誌檔案名稱（使用服務名稱）

### 6. 移除系統腳本自動備份資料庫到 /opt 下其他自定義資料夾
- **狀態**：✅ 已實現
- **位置**：`uninstall.sh` 步驟 2 和步驟 3
- **功能**：
  - **自動列出 /opt 下的所有應用程式**供選擇要移除哪個
  - 顯示每個應用程式的詳細資訊（大小、資料庫數量）
  - **選擇備份模式時，列出 /opt 下的所有資料夾**供選擇備份目標
  - 即使選擇完全移除，也會詢問是否要備份資料庫
  - 備份到用戶選擇的 /opt 下的資料夾
  - 備份目錄命名：`uninstall_<應用名稱>_YYYYMMDD_HHMMSS`

### 7. 還原資料腳本列表備份資料夾中檔案供選單選擇進行還原
- **狀態**：✅ 已實現
- **位置**：`restore.sh` 步驟 3
- **功能**：
  - **自動搜尋 /opt 下所有資料夾中的備份**
  - 列出所有找到的備份（包括目錄備份和壓縮備份）
  - 顯示備份詳細資訊（類型、位置、時間、大小、資料庫數量）
  - 提供選單供用戶選擇要還原的備份
  - 支援還原選項（完整還原、僅資料庫、僅上傳檔案、僅配置）

## 使用說明

### 部署腳本 (deploy.sh)

```bash
sudo ./deploy.sh
```

部署過程中會詢問：
1. **資料夾名稱**（在 /opt 下）
2. **服務 Port**（預設 5000）
3. **服務名稱**（PM2 進程名稱，預設與資料夾名稱相同）
4. **瀏覽器標題**（預設「資料夾權限文管系統」）
5. **備份排程時間**（如果選擇配置自動備份）

### 移除腳本 (uninstall.sh)

```bash
sudo ./uninstall.sh
```

功能：
1. **自動列出 /opt 下的所有應用程式**供選擇
2. 選擇移除模式：
   - 完全移除
   - 保留資料移除（會詢問備份目標資料夾）
   - 僅停止服務
3. **選擇備份目標時，列出 /opt 下的所有資料夾**供選擇
4. 即使選擇完全移除，如果有資料庫也會詢問是否要備份

### 還原腳本 (restore.sh)

```bash
sudo ./restore.sh
```

功能：
1. 自動偵測應用程式目錄
2. **自動搜尋 /opt 下所有資料夾中的備份**
3. **列出所有備份供選擇**（顯示詳細資訊）
4. 選擇還原模式：
   - 完整還原
   - 僅還原資料庫
   - 僅還原上傳檔案
   - 僅還原配置檔案

## 配置範例

### 部署範例

```
資料夾名稱：my-dms-system
服務 Port：8080
服務名稱：dms-service
瀏覽器標題：我的文件管理系統
備份時間：每天凌晨 3:30
```

結果：
- 安裝路徑：`/opt/my-dms-system`
- PM2 服務名稱：`dms-service`
- 監聽端口：`8080`
- 瀏覽器標題：「我的文件管理系統」
- 備份排程：每天 3:30 執行

### 移除範例

如果 /opt 下有：
- `/opt/folder-dev`
- `/opt/folder-prod`
- `/opt/backups`

腳本會：
1. 列出這兩個應用程式供選擇
2. 如果選擇備份模式，列出所有 /opt 下的資料夾供選擇備份目標
3. 備份到選擇的資料夾，例如：`/opt/backups/uninstall_folder-dev_20241201_143000`

### 還原範例

腳本會：
1. 搜尋 `/opt/backups`、`/opt/folder-dev` 等所有資料夾
2. 列出所有找到的備份：
   - `uninstall_folder-dev_20241201_143000`（在 /opt/backups）
   - `auto_20241201_040000.tar.gz`（在 /opt/backups）
   - `uninstall_folder-prod_20241130_120000`（在 /opt/folder-prod）
3. 用戶選擇要還原的備份

## 注意事項

1. **資料夾名稱**：只能包含英數字、底線和連字號
2. **服務名稱**：只能包含英數字、底線和連字號，建議與資料夾名稱不同以便區分
3. **Port**：必須在 1024-65535 範圍內
4. **備份時間**：使用 24 小時制，格式為 HH:MM
5. **備份位置**：備份會保存到選擇的 /opt 下的資料夾中
