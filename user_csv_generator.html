方法一：從 Active Directory 匯入
使用說明：
  1. 從 Active Directory 匯出使用者清單（包含：名稱、Email、描述等欄位）
  2. 選取包含資料的範圍（包含標題行）
  3. 複製（Ctrl+C）
  4. 貼上到下方的輸入框
  5. 系統會自動識別 AD 格式並提取姓名和 Email
支援格式：系統會自動識別 AD 匯出格式，提取完整欄位（姓名、Email、描述、公司、部門）
方法二：從 Excel 貼上
使用說明：

  2. 在 Excel 中準備人員資料（多欄：姓名、Email、部門、公司、職稱、電話、描述）
